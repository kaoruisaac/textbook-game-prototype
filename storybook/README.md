# Textbook Gaming — User Storybook

此資料夾用於保存與整理 **User Stories（使用者故事）**，作為後續 Web Prototype 的需求來源。

## 工作方式
1. 先在這裡記錄並討論使用者角色、目標、情境及期望行為。
2. 每則故事以獨立 Markdown 檔案保存，並標註草稿（Draft）或已確認（Confirmed）；未確認內容不可視為正式需求。
3. 故事確認後，同步至專案根目錄的 `requirements.md`，再據此修改 `prototype/`。
4. 若 Prototype 與故事不一致，先比對已確認的決策，再更新文件與介面。
