# Stone Age Explorer — Learning Tutor User Stories v0.5

> 2026-11-07 · 學生助教需求增補。延續原始 Qrio User Stories v0.2 與 Stone Age Explorer Gameplay v0.3；不覆寫上游故事。

## User Stories（Confirmed）
1. **學生不清楚操作時**，我想隨時在右側開啟小型浮動助教，詢問下一步，且不必離開遊戲畫面。
2. **學生看不懂問題或不知道怎麼回答時**，我希望助教用提示與例子幫我思考，但不要替我選座標、判斷文物或透露標準答案。
3. **學生不知道要問什麼時**，我希望能點選與目前任務階段有關的預設問題，並看到固定、可預期的 Script 回覆。
4. **學生問到遊戲無關的問題時**，助教仍應將對話帶回當前學習目標，不延伸無關話題。
5. **教師回看學習證據時**，我希望看到學生在 Chatbot 送出的提問、何時問／在哪個操作階段問、助教如何回答，將求助視為學習線索之一。

## Prototype v0.5 的互動實作（Demo-only）
- 保留原本 Qrio 探險助手和座標驅動地圖；另外提供浮動 Qrio 學習助教，不佔用地圖輸入權。
- 學生簡介、探索與結果頁可收合／重新打開；桌機預設展開，手機預設按鈕。
- 預設問題隨頁面及 select / reason / hint / discover / collect / feedback 階段切換。
- 自由文字依受控關鍵字比對本地 Script；識別不出／離題問題以固定敘述導回教學內容；不可作為真正 LLM Guardrail 的證據。
- 收集每次**已送出**的輸入，含來源（自由打字／點選）、頁面和階段、可用座標與時間，以及相應助教答覆。全部加入教師的 Raw Learning Trace；新增求助理解候選訊號，不以次數或離題內容自動判分。
- 範例文本不決定實際文物正誤，也不修改遊戲分數或操作狀態。

## 驗收情境
- 點選「怎麼輸入 X / Y 座標？」得到座標操作提示。
- 學生輸入離題問題，助教固定導回目前遊戲步驟。
- 學生要求直接告知正確文物答案，助教只提供判斷線索。
- 從學生簡介提問後開始任務，教師仍可在 Evidence Studio 回看該提問與答覆。
- 390px 裝置可開／關助教、提問、避免水平溢出。
